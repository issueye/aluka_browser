# 重构计划：统一设置页（标签页化）与功能整合

> 状态：**已实现**（本文档保留作为设计记录）
> 关联提交：见 git log「feat: 设置中心标签页化…」

## 背景与目标

当前设置、用户脚本（篡改猴）、扩展是三个互相独立的**全屏覆盖面板**，快捷访问（书签）硬编码在代码里，主页固定为 github.com，代理设置散落在 config 与 UI 中。本次重构目标：

1. **统一设置中心**：采用「左侧管理项导航 + 右侧内容区」布局，并**以标签页形式**呈现（与其他网页标签并列，可关闭），不再是全屏遮罩。
2. **合并用户脚本与扩展**：两者成为设置中心的两个导航项，原独立面板与工具栏按钮移除。
3. **主页可设置**：主页地址进入配置持久化，「常规」项中编辑。
4. **快捷访问 → 标签管理**：书签栏条目迁移为设置中心「快捷访问」项的可视化管理（增删），持久化到配置。
5. **移除网络代理**：配置、UI、Agent 动作全部移除，未来以扩展形式实现。

## 数据与模型设计

### 配置 v2（`%APPDATA%\gio-browser\config.json`）

```json
{
  "home_page": "https://github.com",
  "quick_links": [ { "name": "GitHub", "url": "https://github.com" }, ... ]
}
```

- 移除 `proxy_*` 四个字段（旧文件中的残留字段会被 json 忽略，无需迁移脚本）。
- 缺省时填充默认主页与默认五个快捷链接（与现状一致）。

### 领域模型（browser）

- `Tab` 增加 URL 约定：设置页为固定地址 `gio://settings`、标题「设置」；`IsSettingsTab(t)` 判定。
- `OpenSettings()`：已存在设置标签则激活，否则新建（新标签默认激活语义复用）。
- `CloseTab` 对设置标签：允许关闭；若为最后一个标签则回落主页（复用既有语义）。
- `NavigateActive` 守卫：活跃标签为设置页时忽略导航（地址栏回车不污染设置页）。
- `GoHome` / 新建标签 / 最后一标签回落 → 全部读 `config.HomePage()`（缺省 `https://github.com`，常量改名 `DefaultHomePage`）。
- 书签操作：`Bookmarks()` 读配置；新增 `AddQuickLink(name,url)` / `RemoveQuickLink(i)`，写配置持久化。
- WebView 显隐：`SwitchTab` / `OpenSettings` / `CloseTab` 后统一 `engine.SetVisible(活跃标签非设置页)`。

### WebView 层

- `CreateTab("gio://settings", …)` **不创建** WebView2 实例（URL 前缀守卫直接返回）；设置页无渲染进程开销。
- 活跃标签无视图（设置页）时 `SetVisible(false)` 隐藏 WebView 露出 Gio 设置界面；切回普通标签恢复。既有方法的 nil 视图保护已覆盖 Navigate/Eval 等误用。

### UI 层

- 工具栏：移除「用户脚本」「扩展」两个按钮；「设置」按钮改为打开设置标签（幂等）。
- 快捷访问栏：从初始化快照改为**每帧读配置动态渲染**（按 URL 缓存 Clickable 避免状态闪烁）；空列表显示提示文案。
- `settings.go` 重写为设置中心骨架：左导航（常规/快捷访问/用户脚本/扩展）+ 右侧内容；选中项持久于 UI 状态。
- `userscripts_ui.go` / `extensions_ui.go` 从全屏页改造为**可嵌入面板**（去掉「返回网页」头部，保留列表/编辑器/操作逻辑），由设置页右区调用。
- 「常规」面板：主页地址输入 + 保存；「快捷访问」面板：链接列表（名称/URL/删除）+ 添加行，保存即写配置并即时反映到快捷访问栏。

### 清理

- `config`：删除代理字段、`BuildProxyArgs`、环境变量注入。
- `scripting`：删除 `get_proxy` / `set_proxy` Agent 动作。
- 文档：README 功能列表与已知限制、AGENTS 配置说明同步（代理注明"未来由扩展实现"）。
